# Цели на семестр

1. Освоить Git и GitHub на уровне уверенной командной работы: ветки, pull request’ы, разрешение конфликтов.
2. Научиться собирать и запускать приложения в Docker и писать простые Dockerfile / docker-compose.
3. Настроить свой первый CI/CD-пайплайн на GitHub Actions (сборка, тесты, деплой).
