# Git в VS Code / Cursor vs терминал

## Что удобно в IDE

1. **Визуальный diff** — сразу видно, какие строки добавлены (зелёные) и удалены (красные), без команды `git diff`.
2. **Панель Source Control** — статус файлов, stage/unstage и коммит одной кнопкой, понятно даже без запоминания команд.
3. **История и blame (GitLens)** — видно, кто и когда менял конкретную строку, удобно при разборе чужого кода.

## Что удобнее в терминале

1. **Работа на сервере по SSH** — на удалённой машине часто нет IDE, только CLI; плюс сложные операции (`rebase`, `cherry-pick`, скрипты) проще и надёжнее делать в терминале.
